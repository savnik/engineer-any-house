# VVS – tjeklister

## Projektering
- [ ] Forsyning: stikledning, måler og tryk undersøgt; kapacitet til nye tapsteder
- [ ] Varmtvandsbehov og løsning (beholder, veksler, varmepumpe) samt cirkulation
- [ ] Rørføring som rør-i-rør med tilgængelige samlinger; fordeler med drypbakke/lækagealarm
- [ ] Afløb: fald, dimension, udluftning, renseadgang; snitflade og kote til kloakmester
- [ ] Vådrum: gulvafløb godkendt til gulvopbygning og membransystem; fald; få gennemføringer
- [ ] Tilbagestrømningssikring vurderet efter DS/EN 1717
- [ ] Isolering (DS 452), frostsikring, kondens
- [ ] Varmeanlæg: varmetab, fremløbstemperatur, indregulering; varmepumpens støj og placering
- [ ] Ændres varmekilde eller kedelsikkerhed: fejltilstandstabel (drift, dump, strømsvigt, fastlåst ventil, lækage), uafhængige barrierer, funktionstjek af sikkerhedskæden (tryk og flow til afløbssikring, intet luftgab), ekspansion efter DS/EN 12828
- [ ] Autorisation, tilladelser og forsyningernes bestemmelser afklaret
- [ ] Grænseflader aftalt med el, tømrer, murer/flisemurer og ventilation

## Afleveringstjek – projekteringsnotat (før aflevering og efter hver retur)
- [ ] Krav- og begrænsningsliste fra projektgrundlag og beslutningslog; alle anbefalinger og scenarier (også plan B) overholder den
- [ ] Setpunkt- og grænsetabel: nedre og øvre grænse og kilde pr. parameter; hver rettelse tjekket begge veje
- [ ] Fejltilstandstabel dækker varmeside, brugsvandsside (sikkerhedsgruppe, blander), el-side (elpatron, kontaktor, sikkerhedsbegrænser, 230 V på styringsudgange) og udførelse (hvem er på stedet hvornår)
- [ ] Funktionstjek af alle sikkerhedskomponenter i kæden, både nye og eksisterende, med ansvarlig, metode, acceptkriterium og tidspunkt
- [ ] Brugsvandsarbejde: DS 439 (tæthedsprøvning, gennemskylning, afpropning af blindledninger) og KLS
- [ ] Hold points er tests, der kan udføres, og er delt i "før opstart" og "før anlægget efterlades uovervåget"
- [ ] Budgetsummer og henvisninger efterregnet

## Hold point – før vægge og gulve lukkes
- [ ] Tæthedsprøvning af vandinstallationen udført og dokumenteret efter DS 439 (dec. 2024) og producent; tomrør kontrolleret
- [ ] Gennemskylning i byggefasen (mindst hver 7. dag før ibrugtagning, jf. DS 439:2024) planlagt
- [ ] KLS-slutkontrol dokumenteret (udfører, kontrollant, dato, resultat)
- [ ] Afløb tæthedsprøvet; fald kontrolleret
- [ ] Fotos med mål af rørføringer, samlinger og fastgørelser
- [ ] Gulvafløb og gennemføringer placeret korrekt i forhold til membran- og fliseplan
- [ ] Isolering monteret

## Idriftsættelse og aflevering
- [ ] Skylning; evt. desinfektion
- [ ] Temperaturer målt (varmt vand, cirkulationsretur)
- [ ] Varmeanlæg afluftet og indreguleret – protokol vedlagt
- [ ] Sikkerhedsventiler, afspærringer og stophane funktionstestet
- [ ] Som-udført-tegning, D&V-materiale, datablade og godkendelser (VA/MK)
- [ ] Brugerinstruktion: fordeler, afspærring, varmepumpe/fjernvarmeunit, service
