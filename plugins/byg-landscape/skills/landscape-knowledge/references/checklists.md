# Anlægsgartner – tjeklister

## Forundersøgelse
- [ ] Koter: sokkel, fugtspærre, dørtrin, brønde, skel; eksisterende fald
- [ ] Jordbund og grundvand: prøvegravning, nedsivningstest ved faskine
- [ ] LER-forespørgsel og kendte stikledninger, kloak og dræn
- [ ] Lokalplan og servitutter: terrænregulering, hegn, træer, belægning
- [ ] Spildevandsplan og nedsivningstilladelse; afstandskrav for faskine
- [ ] Jordforureningskortlægning og områdeklassificering (overskudsjord)
- [ ] Skel og skelpæle; nabohegn og aftaler
- [ ] Vandveje ved skybrud; nedløb og deres tilslutning
- [ ] Træer ved hus, fundament og afløb; invasive arter

## Myndighedsscreening (skriv resultatet i notatet)
- [ ] Hævet terrasse > 0,30 m over terræn → 2,5 m til skel (BR18 § 179)?
- [ ] Terrænregulering inden for lokalplanens grænser (højde og afstand til skel)?
- [ ] Nedsivning: tilladelse søgt, afstande overholdt?
- [ ] Kloakarbejde (tilslutning, afkobling, omfangsdræn) → kloakmester?
- [ ] Hegn i skel: aftale med nabo eller varsel?
- [ ] Jordflytning: anmeldelse til kommunen?

## Hold points
- [ ] **HP-ANL-1 Ledninger og myndighed:** LER, nedsivningstilladelse og lokalplan afklaret, før der graves
- [ ] **HP-ANL-2 Udgravning og bund:** bundforhold, dybde og sikring af udgravning kontrolleret, før bærelag lægges
- [ ] **HP-ANL-3 Bærelag og fald:** komprimering og fald (nivellement) kontrolleret, før sættelag og belægning
- [ ] **HP-ANL-4 Faskine og dræn:** faskine, brønde og rør kontrolleret og fotodokumenteret før tildækning; kloakmesterens færdigmelding modtaget

## Aflevering
- [ ] Fald kontrolleret (nivellement eller vandprøve) – intet bagfald mod huset
- [ ] Fri sokkel overholdt
- [ ] Fuger fyldt, kanter fastholdt, ingen sætninger
- [ ] Faskine: tegning med placering, dybde og dimension; tilladelse og færdigmelding arkiveret
- [ ] Plejeplan og vandingsvejledning til bygherren
- [ ] Fotodokumentation af skjulte dele (bærelag, faskine, dræn)
