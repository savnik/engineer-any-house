# Statiker – tjeklister

## Forundersøgelse
- [ ] Opførelsesår, konstruktionstype, etager, kælder, tagtype (hanebånd, åse, gitterspær) – BBR, tegninger, fotos
- [ ] Bjælkelagets retning, dimension, afstand og spænd over og under indgrebet – målt eller åbnet
- [ ] Vægtype og -tykkelse; hvad står ovenpå og nedenunder (væg, drager, fundament)
- [ ] Vederlagssteder for en ny bjælke: murværkets tilstand, pillebredde, hvad pillen står på
- [ ] Fundament under nye punktlaster: prøvegravning eller tegning; jordbund ved tvivl (geotekniker)
- [ ] Stabilitet: er væggen afstivende? Hvad afstiver huset i stedet?
- [ ] Laster før og efter (tagdækning, gulve, bad, tagetage, solceller, installationer)
- [ ] Skader: revner (mønster, bredde, udvikling), nedbøjning, råd, korrosion – fotos med målestok
- [ ] Problemstoffer i de dele, der rives ned (asbest, PCB, bly) – screening før indgreb
- [ ] Myndighed: tilladelse eller ej, konstruktionsklasse, hvem udarbejder statisk dokumentation

## Betonskade i fundament, sokkel eller kældervæg
- [ ] Bærer den skadede del noget (ydervæg, vederlag, åbning, teglskifte, søjle)?
- [ ] Skadekort: hvert sted med areal og dybde fra oprindelig overflade, fotos med målestok; bank-test i gitter
- [ ] Dybde mod væggens tykkelse (restareal); sund bund nået ved udhugning med håndværktøj?
- [ ] Revner: retning, bredde i faste punkter, forskydning, gennemgående, fortsætter i murværket; limede mærker og aflæsningsplan
- [ ] Mekanisme sandsynliggjort (udvaskning, stenrede, frost, sulfat, korrosion); prøver ved tvivl (borekerne, tyndslib, sulfat, karbonatisering)
- [ ] Vandkilden fundet og plan for at standse den (nedløb, terræn, dræn, kloak)
- [ ] Udfald: overfladisk / lokal konstruktiv / konstruktiv-sætning, og hvem der udfører
- [ ] Stop-kriterier skrevet til bygherren (forskydning, udbuling, voksende revne, nedfald)
- [ ] Screening af lag, der fjernes (asbest, PCB, bly); kvartsstøv ved hugning

## Hold points
- [ ] **HP-STAT-1 Afdækning:** konstruktionen åbnet og målt; antagelserne i overslaget bekræftet eller rettet før endelig dimensionering
- [ ] **HP-STAT-2 Midlertidig understøtning:** stempler/nåle placeret efter projekt og på bæredygtigt underlag, før noget bærende fjernes
- [ ] **HP-STAT-3 Vederlag og fundament:** udstøbning, vederlagsplade, pille og evt. punktfundament kontrolleret før montering og belastning
- [ ] **HP-STAT-4 Montage:** profil/dimension, stålkvalitet eller styrkeklasse, samlinger og beslag som projekteret – før lukning og beklædning
- [ ] **HP-STAT-5 Afslutning:** understøtning fjernet efter hærdetid; nedbøjning og revner kontrolleret
- [ ] **HP-STAT-6 Betonreparation:** udhugning til sund beton, etaper og understøtning kontrolleret og fotograferet med målestok, før der støbes eller lægges reparationsmørtel

## Aflevering
- [ ] Statisk dokumentation (eller overslag tydeligt markeret) og konstruktionsgrundlag i sagsmappen
- [ ] Fotos fra hvert hold point med dato
- [ ] Følgesedler/certifikater for stål (kvalitet) og konstruktionstræ (CE og styrkeklasse)
- [ ] Afvigelser fra projektet godkendt af den ansvarlige statiker
- [ ] Revneovervågning: plan for opfølgning, hvis der var aktive revner
- [ ] Kommunen: dokumentation indsendt, når det kræves; færdigmelding ved tilladelsessager
