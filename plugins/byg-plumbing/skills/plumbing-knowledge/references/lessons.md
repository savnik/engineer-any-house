# VVS – forankrede erfaringsblade

Reviewede, generaliserbare erfaringer. Nye blade kommer via `/byg:lessons` (forankringskøen) og lægges først her, når de er godkendt.

Format:
```
### EB-VVS-<nr>: <titel>
- Situation / Problem / Løsning
- Grundlag: [KRAV]/[NORM]/[ANVISNING]/[ERFARING] med kilde
- Gyldighed: hvornår gælder erfaringen – og hvornår ikke
- Status: verificeret | erfaring · Dato
```

### EB-VVS-001: Fordelerskab uden drypbakke giver skjulte skader
- Situation: fordelerunit indbygget i skab i gang, køkken eller skunk.
- Problem: små utætheder opdages først som gulv- eller vægskader.
- Løsning: drypbakke med afløb eller lækagealarm; fordeler helst i vådrum; afspærring pr. streng og mærkning.
- Grundlag: [KRAV] BR18 §406 – utætheder skal let kunne konstateres. [ERFARING] branchepraksis.
- Gyldighed: alle skjulte vandinstallationer.
- Status: verificeret (§406) · 2026-09-25

### EB-VVS-002: Bland aldrig vådrumssystemer
- Situation: gulvafløb, membran og fliseklæb fra forskellige leverandører.
- Problem: tætheden er ikke dokumenteret, og systemgodkendelsen bortfalder.
- Løsning: vælg ét godkendt system, og kontrollér gulvafløbets godkendelse til den konkrete gulvkonstruktion og belægning.
- Grundlag: [ANVISNING] BUILD/SBi 252; MK-/VA-godkendelsernes vilkår.
- Status: verificeret · 2026-09-25

### EB-VVS-003: Varmepumpe på gamle radiatorer
- Situation: konvertering fra olie, gas eller fjernvarme til luft/vand-varmepumpe.
- Problem: radiatorer dimensioneret til høj fremløbstemperatur → kolde rum eller dårlig virkningsgrad.
- Løsning: varmetabsberegning og radiatorvurdering rum for rum; større eller ekstra radiatorer eller gulvvarme; indregulering.
- Grundlag: [ERFARING] branchepraksis.
- Status: erfaring · 2026-09-25
