# Maler – tjeklister

## Forundersøgelse
- [ ] Opførelsesår og tidligere behandlinger; bevaringsværdi
- [ ] Bly-test (før ca. 1980) og PCB-screening (1950–1977) før afrensning
- [ ] Fugtmåling og årsag til skader (fugt bagfra, råd, salte)
- [ ] Vedhæftning og lagopbygning
- [ ] Affald: mængde, stoffer, anmeldelse vurderet

## Beskrivelse og aftale
- [ ] Behandling efter MBK eller datablad; system fra én leverandør
- [ ] Q-niveau, farver, glans og prøvefelt aftalt skriftligt
- [ ] Indfaldskrav til forrige fag (underlag, fugt, hærdetid)
- [ ] Vejrlig og tørretider i tidsplanen
- [ ] MAL-koder og arbejdsmiljø (ventilation, sprøjtning, værnemidler)

## Hold points
- [ ] Underlag godkendt (fugt, vedhæftning, rengøring) før første strøg
- [ ] Afrensning af bly/PCB udført efter plan; affald håndteret
- [ ] Vådrum: zoner kontrolleret – membran i vådzonen udført af andet fag før malerbehandling i fugtig zone
- [ ] Mellemstrøg kontrolleret (lagtykkelse, dækning)

## Aflevering
- [ ] Udfaldskrav opfyldt (dækket, lukket, glat m.m. – efter aftale/MBK)
- [ ] Produktdatablade, systembeskrivelse og farvekoder
- [ ] Vedligeholdelsesvejledning (fx vinduer: eftersyn årligt, linolie efterbehandling; vådrum: eftersyn hvert 4.–8. år)
