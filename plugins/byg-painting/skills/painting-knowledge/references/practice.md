# Maler – faglig praksis på mesterniveau

Værdier markeret **(T)** er typiske branche- eller erfaringsværdier. Verificér mod MBK, datablad eller prøve, før de bruges som krav.

## 1. Underlagsanalyse – før noget andet
| Test | Formål | Praksis |
|---|---|---|
| Fugtmåling | Træ, puds, beton, gips | Træ udvendigt under ca. 14 % ved linoliemaling (sekundær kilde – krydstjek MBK); mineralske underlag efter datablad; mål på vejrsiden og nederst |
| Vedhæftning | Sidder den gamle maling fast? | Tapeprøve/kryds-ridse (T: fx DS/EN ISO 2409-princip); løs maling skal af |
| Lagopbygning og type | Hvad er der malet med? | Kig i brudkanten; opløsningsmiddeltest (T); kalk smitter af og opløses i fortyndet syre (T) |
| Bly og PCB | Sundhed og affald | Hus før ca. 1980: test (hurtigtest eller laboratorium); fuger og maling fra 1950–1977: PCB-screening |
| Sugeevne og kridtning | Grunding og vedhæftning | Vanddråbe-test; kridtet overflade afrenses og grundes efter system |
| Salte og alkalitet | Mineralske underlag | Saltudblomstring = fugtvej (murer); ny puds/beton er alkalisk – alkyd kan forsæbes (T) |

## 2. Systemvalg
| Underlag | Egnet | Undgå |
|---|---|---|
| Gamle trævinduer og døre (linoliemalede) | Linoliemaling i tynde lag, linoliekit, efterbehandling med linolie | Akryl/plast oven på linolie; tykke lag; varmluft og afbrænding |
| Nyt udvendigt træ | Komplet system fra én leverandør (grunder, mellem- og topstrøg), endetræsforsegling | Maling af vådt eller beskidt træ; overspring af grunding |
| Kalkpuds og gamle murede facader | Kalk (kalkning) eller silikatmaling efter underlagsanalyse | Akryl-/plastmaling og tætte systemer på fugtigt, ældre murværk |
| Ny puds, beton | Silikat eller facadeakryl efter datablad; alkalitet og hærdetid respekteres | Alkyd på friskt, alkalisk underlag (T) |
| Gips og indvendige vægge | Spartel til aftalt Q-niveau, grunder, vægmaling med glans efter rumtype | Ubehandlede spartelpletter (gennemslag); forkert glans i køkken/gang |
| Vådrum, fugtig zone | Dokumenteret vådrumsmalesystem (fx MK 7.00/018-godkendt) | Almindelig vægmaling; maling i vådzonen i stedet for membran |
| Metal | Afrensning, korrosionsbeskyttende grunder og system | Maling på løs rust; afbrænding/slibning af blymønje uden sikring |

## 3. Afrensning og forbehandling
- **Mistanke om bly:** ingen tør maskinslibning, ingen afbrænding, varmluft eller "speedheater". Kold, våd, partiel afskrabning af løs maling; støvsuger med mindst H13-filter; afdækning; personlige værnemidler; affaldet opbevares og afleveres efter kommunens anvisning (grænser i normgrundlag).
- **PCB-mistanke** (fuger og maling 1950–1977): prøve før nedrivning; fjernelse og affald efter kommunens regler; anmeldelse af affald hvor krævet.
- Rengøring (alger, fedt, smuds), udbedring (kit, spartel, træreparation ved tømrer) og grunding efter system.

## 4. Gamle vinduer (linolie)
Afrens løs maling manuelt → rens og tør → reparér træ (tømrer ved råd) og kit → grund med linolie/linoliemaling → 2–3 tynde lag linoliemaling, inkl. kitfals og ca. 2 mm ud på glasset (V: SLKS) → gennemhærdning 3–5 uger (V: TI). Mal i tørt vejr, gerne sensommer, med ventilerede, tørre rammer.

## 5. Facader
- Kalk og silikat kræver mineralsk underlag uden plastrester. Test om den gamle behandling er plast (T: opløsningsmiddel/brænd-lugt ved skrab).
- Fugt først: afskalning i sokkelzonen og under sålbænke skyldes oftest fugtvej – koordinér med murer før maling.
- Vejrlig: ingen maling på fugtigt underlag, i regn, direkte sol på varme flader eller under producentens minimumstemperatur (typisk ≥ +5 °C – T).

## 6. Vådrum
- Fugtig zone: vandtæt malebehandling med dokumenteret system; vådzonen skal have membran (flisemurer/murer). Kontrollér zonerne på tegningen (SBi 252).
- Underlag efter systemet (gips med tilstrækkelig vandfasthed, Z-værdi-krav i MK 7.00/018); bland ikke systemer; eftersyn hvert 4.–8. år (Danske Malermestre).

## 7. Skimmel
Stop – find årsagen først (ventilationsekspert, murer, vvs, tømrer). Vurdér omfang (SBi 274: 0,06 m² synlig vækst pr. ca. 100 m² bolig som vejledende grænse), afrens efter SBi 281 med værnemidler, lad tørre, og mal først når fugtkilden er fjernet. Antiskimmelmaling uden årsagsfjernelse er symptombehandling.

## 8. Spartling og overfladekvalitet
Aftal Q-niveau skriftligt (Q2 er standard, hvis intet er angivet; Q3 skal beskrives; Q4 = fuldspartling) og vurdér lysforholdene – strejflys fra store vinduer eller spots afslører alt. Prøvefelt ved Q3/Q4.

## 9. Arbejdsmiljø
MAL-koden styrer ventilation og værnemidler; vælg lavest mulige kode. Sprøjtemaling, isocyanat- og epoxyprodukter kræver særlige forholdsregler og evt. uddannelse (T). Støv fra slibning af gamle behandlinger kan indeholde bly.

## 10. Grænseflader set fra maler
| Fag | Maler forventer | Maler leverer |
|---|---|---|
| Tømrer | Træreparation, råd udskiftet, lister og beklædning færdige | Krav til træfugt og overflade |
| Murer | Tørt, afbundet underlag; fugtkilder løst; pudsens hærdetid oplyst | Underlagsvurdering, system efter underlag |
| VVS/el/ventilation | Installationer færdige og fastgjort før slutmaling | Afdækning og efterbehandling |
| Flisemurer | Membran i vådzonen, tydelig zoneafgrænsning | Malesystem i fugtig zone |
| Projektleder | Q-niveau, farver, glans og tidsplan med tørretider | Tørretider og vejrkrav til tidsplanen |
