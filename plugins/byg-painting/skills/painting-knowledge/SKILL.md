# Maler-videnbase

| Fil | Indhold | Læs når |
|---|---|---|
| `references/standards.md` | MAL-koder, bly/PCB, MBK, vådrum, skimmel, Q-niveauer – status | Krav, arbejdsmiljø, affald |
| `references/practice.md` | Underlagsanalyse, systemvalg, afrensning, vinduer, facader, vådrum, skimmel, spartling | Projektering, vurdering, fejlfinding |
| `references/checklists.md` | Forundersøgelse, beskrivelse, hold points, aflevering | KS, tilbud, aflevering |
| `references/lessons.md` | Reviewede, forankrede erfaringer | Altid – hurtigt skim |

## Brug uden subagent
Kører du ikke som `painter`-agenten, så læs `${CLAUDE_PLUGIN_ROOT}/agents/painter.md` og arbejd efter dens rolle, kerneprincipper og fælles protokol.
