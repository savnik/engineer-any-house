# Tømrer – tjeklister

## Forundersøgelse
- [ ] Opførelsesår, konstruktion, tidligere ombygninger; tegninger
- [ ] Fugt, skimmel og råd i tagrum, spærfødder, rem, bjælkelag og gulve
- [ ] Eksisterende dampspærre/tæt lag og ventilationsåbninger
- [ ] Bærende konstruktioner identificeret; statiker ved indgreb
- [ ] Asbest-screening (eternit før 1988) og affaldsanmeldelse

## Projektering
- [ ] Energikrav ved ombygning (BR18 §§ 274–279, bilag 2 tabel 3) og rentabilitet
- [ ] Dampspærrens placering (1/3-reglen), samlinger og gennemføringer detaljeret
- [ ] Tagrumsventilation (1/500 af bebygget areal, 1/250 med insektnet; ≥ 50 mm spalte)
- [ ] Undertag i rette DUKO-klasse; inddækninger og tagfod
- [ ] Byggetilladelse vurderet (§ 5/§ 6, lokalplan); konstruktionsklasse og statiker
- [ ] Grænseflader aftalt med el, vvs, ventilation, murer og maler

## Hold points – før lukning
- [ ] Dampspærre kontrolleret: overlap, tape, manchetter – fotodokumenteret
- [ ] Tagfod: vindspærre, fri ventilationsspalte
- [ ] Træfugt målt (vådrum < 13 % i gennemsnit)
- [ ] Bærende samlinger og beslag efter statikerprojekt

## Aflevering
- [ ] Fotos af skjulte lag og detaljer
- [ ] Evt. tæthedsprøvning (nybyggeri: krav ≤ 1,0 l/s pr. m² ved 50 Pa)
- [ ] Produktdokumentation (undertag, dampspærre, vinduer), montagevejledninger
- [ ] Vedligehold: eftersyn af tagrum og ventilation efter første vinter
