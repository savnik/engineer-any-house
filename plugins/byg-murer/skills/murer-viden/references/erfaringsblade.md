# Murer – forankrede erfaringsblade

Reviewede, generaliserbare erfaringer. Nye blade kommer via `/byg:erfaring` (forankringskøen) og lægges først her, når de er godkendt.

Format: `### EB-MUR-<nr>: <titel>` med Situation/Problem/Løsning, Grundlag, Gyldighed, Status og dato.

### EB-MUR-001: Hård cementfuge i gammelt kalkmurværk
- Situation: facade fra før ca. 1930 med bløde sten og kalkmørtel omfuges med cementholdig "stærk" mørtel.
- Problem: fugen er stærkere og tættere end stenen; fugt og bevægelser tages af stenen → afskallede stenkanter, frostsprængning, løse fuger efter få vintre.
- Løsning: bestem eksisterende mørtel (evt. analyse), prøvefelt, kalk- eller svag KC-mørtel svagere end stenen, skånsom udkradsning ca. 2 cm, efterbehandling mod udtørring og frost.
- Grundlag: [ANVISNING] Slots- og Kulturstyrelsen 3.1 Murværk; Bolius; kommunale bevaringsvejledninger.
- Gyldighed: ældre murværk opmuret i kalk. Ikke nødvendigvis moderne murværk i KC-mørtel og hårde sten.
- Status: verificeret · 2026-09-25

### EB-MUR-002: Indvendig isolering af kældervæg uden fugtanalyse
- Situation: kælder skal gøres til beboelse; væggene isoleres indvendigt med mineraluld og dampspærre.
- Problem: væggen bag isoleringen bliver kold og fugtig; fugt fra jord og indeluft fanges → skimmel og lugt, ofte skjult i årevis.
- Løsning: fugtkilder og fugtniveau undersøges først; udvendig fugtsikring som førstevalg; indvendigt kun dokumenteret diffusionsåbent, kapillaraktivt system efter fugtteknisk vurdering; ventilation og affugtning.
- Grundlag: [ANVISNING] fugtteknik (BUILD); [ERFARING] skadessager.
- Gyldighed: kældre og vægge mod jord i ældre huse.
- Status: erfaring · 2026-09-25

### EB-MUR-003: Tæt maling på gamle, fugtige mure
- Situation: ældre sokkel eller kældervæg males med plast- eller akrylmaling "for at holde fugten ude".
- Problem: fugt og salte kan ikke fordampe → malingen bobler og skaller, puds og sten nedbrydes bag filmen.
- Løsning: fjern tætte lag; find fugtkilden; kalk- eller silikatbehandling efter underlagsanalyse.
- Grundlag: [ERFARING] branchepraksis; [ANVISNING] producentsystemer.
- Status: erfaring · 2026-09-25
