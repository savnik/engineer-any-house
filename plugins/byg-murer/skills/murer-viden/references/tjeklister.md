# Murer – tjeklister

## Forundersøgelse
- [ ] Opførelsesår, byggeskik, bevaringsværdi/fredning/lokalplan
- [ ] Eksisterende mørtel (type, hårdhed, farve) – evt. analyse; sten (blød/hård, sugeevne)
- [ ] Fugtkilder: tagrender, nedløb, terræn, sokkel, slagregn, installationer; fugtmåling
- [ ] Revner kortlagt, klassificeret og evt. overvåget
- [ ] Bærende/ikke-bærende vægge afklaret (tegninger, bjælkelag) – statiker ved tvivl
- [ ] Screening for asbest, PCB og bly før nedrivning, fræsning og slibning
- [ ] Affaldsanmeldelse vurderet (> 10 m² eller > 1 ton)

## Projektering
- [ ] Mørtelrecept valgt ud fra eksisterende murværk (svagere end stenen)
- [ ] Prøvefelt planlagt (recept, farve, fugeform)
- [ ] Vejrlig og årstid: ingen frost, beskyttelse mod sol, vind og slagregn
- [ ] Kælder: udvendig løsning vurderet først; indvendig isolering kun med fugtteknisk vurdering
- [ ] Bærende indgreb: statikerprojekt, midlertidig understøtning, overligger og vederlag
- [ ] Vådrum: underlag, fald, ét godkendt membransystem, gulvafløb koordineret med VVS
- [ ] Grænseflader aftalt: tømrer, vvs, el (riller), ventilation, maler, kloakmester, statiker
- [ ] Støvbegrænsning og arbejdsmiljø (kvartsstøv, stillads, tunge løft)

## Hold points
- [ ] Prøvefelt godkendt af bygherre før fuld udførelse
- [ ] Udkradsningsdybde og stenkanter kontrolleret før fugning
- [ ] Midlertidig understøtning og overligger kontrolleret før nedbrydning af bærende væg
- [ ] Vådrum: fald målt (ingen lunker/bagfald); membranens lagtykkelse og tilslutninger kontrolleret og fotograferet før fliser
- [ ] Fugt i trækonstruktioner < 13 % (gennemsnit) før vådrumsopbygning

## Aflevering
- [ ] Mørtelrecept, produktdatablade og MK-godkendelser (vådrum)
- [ ] Fotodokumentation af skjulte lag (membran, armering, overliggere, bindere)
- [ ] Vedligeholdelsesvejledning (fuger, kalkning, efterse tagrender og terræn)
- [ ] Revneovervågning: plan for opfølgning efter en vinter, hvis relevant
