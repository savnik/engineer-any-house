# Maler-videnbase

| Fil | Indhold | Læs når |
|---|---|---|
| `references/normgrundlag.md` | MAL-koder, bly/PCB, MBK, vådrum, skimmel, Q-niveauer – status | Krav, arbejdsmiljø, affald |
| `references/faglig-praksis.md` | Underlagsanalyse, systemvalg, afrensning, vinduer, facader, vådrum, skimmel, spartling | Projektering, vurdering, fejlfinding |
| `references/tjeklister.md` | Forundersøgelse, beskrivelse, hold points, aflevering | KS, tilbud, aflevering |
| `references/erfaringsblade.md` | Reviewede, forankrede erfaringer | Altid – hurtigt skim |

## Brug uden subagent
Kører du ikke som `malermester`-agenten, så læs `${CLAUDE_PLUGIN_ROOT}/agents/malermester.md` og arbejd efter dens rolle, kerneprincipper og fælles protokol.

## Statusmærker
**V** = verificeret mod kilde (dato). **T** = skal verificeres før brug som krav.
