# Ventilation – tjeklister

## Projektering
- [ ] Løsningstype valgt ud fra bygning, ombygningsomfang og brugsmønster (naturlig, udsugning, balanceret, decentral)
- [ ] Luftmængder efter BR18 kap. 22: udeluft 0,3 l/s pr. m²; forøget udsugning køkken 20, bad 15, wc/bryggers/kælder 10 l/s; emhætte
- [ ] Erstatningsluft og overstrømning for hvert udsugningsrum
- [ ] Vinduesudskiftning: ventilationsforholdene fra opførelsen opretholdes (friskluftventiler)
- [ ] Ildsted, brændeovn eller åben gaskedel? Undertryk vurderet, erstatningsluft sikret, skorstensfejer involveret
- [ ] Varmegenvinding ≥ 80 % tør temperaturvirkningsgrad og SEL ≤ 1.000 J/m³ (anlæg til én bolig) – tjek aktuel BR18
- [ ] Kanalføring, isolering (DS 452), kondens, afkast over tag, afstand mellem indtag og afkast
- [ ] Brandsikring efter DS 428 ved brandadskillelser
- [ ] Lyd: ≤ 30 dB fra installationer i beboelsesrum og køkken; lyddæmpere, krydstale mellem soverum
- [ ] Grænseflader: el (forsyning, styring), vvs (kondensafløb), tømrer (plads, dampspærre, undertag), murer (huller, brandtætning)

## Hold points – før lukning
- [ ] Kanaler tætte, samlinger tapet, tæthedsprøvning efter projekt
- [ ] Isolering af kanaler monteret; diffusionstæt på kolde kanaler i varme rum
- [ ] Gennemføringer i dampspærre og undertag tætnet med manchet
- [ ] Brandtætning og brandspjæld monteret og dokumenteret
- [ ] Rensningsadgang og lemme placeret

## Indregulering, funktionsafprøvning og aflevering
- [ ] Indregulering: luftmængde målt pr. ventil, rapport
- [ ] Funktionsafprøvning før ibrugtagning (BR18 § 450): SEL, luftmængder, behovsstyring dokumenteret
- [ ] Kondensafløb, frostsikring og filtre kontrolleret
- [ ] D&V-manual efter DS 447 (§ 452), filterplan og brugerinstruktion
- [ ] Resultat af funktionsafprøvning indsendt ved færdigmelding (når byggesag)
